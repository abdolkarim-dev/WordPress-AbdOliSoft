## 📖 درباره پروژه

**WordPress-MyCity** یک پروژه جامع و کامل برای نمایش و مدیریت تمامی بخش‌های یک شهر است. این پروژه با هدف ایجاد یک پلتفرم یکپارچه برای معرفی شهر و ارائه خدمات متنوع به شهروندان طراحی و پیاده‌سازی شده است.

> 💡 **ایده اصلی:** ایجاد یک درگاه واحد برای دسترسی شهروندان به تمامی اطلاعات و خدمات شهری

## 🛠️ نصب و راه‌اندازی

### پیش‌نیازها

* PHP 8.x یا بالاتر
* MySQL 5.7 یا بالاتر
* Composer
* Node.js & NPM (برای کامپایل Tailwind)

### مراحل نصب

```bash
# 1. کلون کردن پروژه

git clone https://github.com/abdolkarim-dev/WordPress-MyCity.git

# 2. ورود به پوشه پروژه

cd WordPress-MyCity

# 3. نصب وابستگی‌های PHP

composer install

# 4. نصب وابستگی‌های Node

npm install

# 5. ساخت فایل‌های CSS

npm run build

# 6. تنظیم فایل wp-config.php
# اطلاعات دیتابیس را وارد کنید

# 7. نصب وردپرس
# از طریق مرورگر به آدرس پروژه بروید و مراحل نصب را کامل کنید
```
